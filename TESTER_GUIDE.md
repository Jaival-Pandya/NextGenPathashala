# NextGenPathashala — early tester guide

Thank you for testing NextGenPathashala. The aim of this early pilot is to learn whether it makes daily class coordination clearer for schools, colleges and tuition/coaching institutes.

## Before you start

- Use your own test workspace and fictional data.
- Do not upload or enter real student records, grades, health information or passwords you use elsewhere.
- Keep your current register/software as the source of truth during this MVP test.
- Try it on the phone or computer you normally use.

## Test it in 10–15 minutes

### 1. Create a test workspace

Open the website and choose **Create a test workspace**. Register a test administrator using a unique email address and a strong password.

### 2. Set up one class

Open **Classes & people**, create a class or batch (for example, `Demo Batch A`), and add one teacher and one student with fictional details. Enroll the student into the batch.

### 3. Try the timetable

Open **Timetable**, choose the class, enter a subject, select the teacher, set a start/end time and create a session. Try a conflicting session to see whether the app warns you.

### 4. Try attendance

Sign out and sign in as the test teacher using the account created by the administrator. Choose the session and mark the sample student present or absent. Save it, then sign in as the student to verify that the history appears.

### 5. Try homework and notices

As an administrator or teacher, create an assignment and publish a notice for the batch. Sign in as the student and check that both are visible. Submit a short sample response to the assignment.

### 6. Report feedback

Open **Feedback** inside the dashboard. Select the category, name the page and describe:

- What you were trying to do.
- What you expected to happen.
- What actually happened.
- What would make it easier or more useful.

Do not include passwords or sensitive student information in feedback.

## What to evaluate

| Area | Questions to ask yourself |
|---|---|
| Setup | Was creating a class and adding accounts straightforward? |
| Timetable | Could you schedule the class without confusion? |
| Attendance | Could you open the right register and save records quickly? |
| Homework | Were the instructions and due date easy to find? |
| Notices | Was the audience clear? Could you find the notice later? |
| Mobile use | Were text, controls and tables comfortable to use on your device? |
| Trust | Did the app explain what is and is not ready for production? |
| Overall value | Which task, if any, would you actually use this for every day? |

## What to send back

Give one overall rating from 1 to 5, then share the biggest issue and the one improvement that would make you more likely to use the app. Honest negative feedback is useful; there is no need to be polite at the expense of accuracy.
